# What is a Pattern?

A Pattern is repeated activity Onceaway noticed. It is an observation about
**structure**, not a statement about what your work means.

## How Onceaway notices one

Onceaway keeps a simple record of the shape of what happened: which app came to
the front, when you moved to another one, and — in the folders you have allowed
— that a file of a certain type was created, renamed or moved.

It then looks for the same run of steps happening again. When the same shape
turns up more than once, that is a Pattern.

A Pattern might be something like *"a text file appears in Downloads, then
Finder comes forward"*, repeated across an afternoon. Onceaway can see that the
sequence recurred. It has no idea whether you were filing invoices or tidying
holiday photos.

## Why it says "structure, not certainty"

Two sequences that look identical to Onceaway can be completely different jobs,
and two sequences that look different can be the same job done slightly
differently. Onceaway is deliberately cautious about this. It shows you what it
saw and asks you.

## What each Pattern shows you

- A plain title built from what was observed, such as
  *TextEdit · TXT created · Finder*.
- How many times it was seen, and over how many days.
- The individual occurrences, if you want to look.
- A review question: **were these really the same activity?**

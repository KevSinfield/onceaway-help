# What do notifications mean?

The bell in the top right tells you when something is waiting for a decision.
Onceaway is quiet the rest of the time.

## The four kinds

| Notification | What it means | What to do |
| --- | --- | --- |
| **Review needed** | A repeated activity was noticed and has no answer yet. | Say whether it really was the same task. |
| **Opportunity ready** | A confirmed Pattern is now Promising or Strong, and you have not said whether you want help with it. | Answer yes, maybe or no. |
| **Ideas ready** | A suggestion you asked for has arrived and you have not read it. | Read it and decide. |
| **Assist ready** | A Pattern is eligible for the assisted file move. | Use it, or ignore it. |

## They are not an inbox

Notifications are worked out from the state Onceaway is currently in, not
stored as a permanent list. When the underlying situation is resolved — you
reviewed the Pattern, you set the preference — the notification stops existing,
because there is nothing left to tell you.

Ideas-ready notifications also disappear when you quit, because the suggestions
themselves are session-only.

## Nothing a notification does is automatic

Clicking a notification takes you to the relevant screen. It never performs an
action, never moves a file, and never asks an AI provider for anything.

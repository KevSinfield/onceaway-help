# What is Assist?

Assist is Onceaway doing something for you, once you have approved exactly what
it will do.

## What it can do today

One thing: **move a single file you chose into a folder you chose.**

That is the entire current scope. It is small on purpose. Assist is the part of
the product that touches your files, so it grows slowly and only in ways that
can be reviewed before they happen.

## How a move works

1. You press **Choose file** and pick the file yourself.
2. You press **Choose destination** and pick the folder yourself.
3. Onceaway shows you a preview in plain words: this file, from this folder, to
   this folder.
4. Nothing has happened yet.
5. You press **Perform Move**. Only now does anything change on disk.

If the destination already contains a file with that name, Onceaway stops and
changes nothing rather than overwriting anything.

## What it will never do

It never deletes, never overwrites, never acts in the background, and never
starts from something it observed or something an AI suggested.

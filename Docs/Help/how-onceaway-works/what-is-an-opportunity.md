# What is an Opportunity?

An Opportunity is a Pattern you have confirmed, which has happened often enough
to be worth a look.

## How Onceaway weighs it

It considers how often the activity happened, across how many separate days,
and how much real file or browser work was involved rather than just switching
between windows. From that it places the Pattern in one of three bands:

| Band | What it means |
| --- | --- |
| **Strong opportunity** | Repeated across days, with several kinds of work involved. |
| **Promising** | Repeated often enough to be worth a look. |
| **Early signal** | Not yet confirmed, or seen only a little so far. |

Rejected Patterns never appear here at all.

## What it deliberately does not tell you

Onceaway does not estimate how much time this costs you, or what it is worth in
money. It cannot honestly measure either of those things from what it observes,
so it does not pretend to. It tells you what recurred and how strongly, and
leaves the judgement to you.

## What you do with it

Each Opportunity asks one question: **would you like Onceaway to help reduce
this activity?** Answering **Yes** records that you care about it. It sets
nothing up and runs nothing.

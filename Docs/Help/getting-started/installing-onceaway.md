# Installing Onceaway

Onceaway is a normal Mac app. You drag it to your Applications folder and open
it. There is nothing else to install.

## What you need

- A Mac running macOS 15 or later.
- Nothing else. You do **not** need Xcode, developer tools, Homebrew, or a
  copy of the source code. Everything the app needs is inside it.

Onceaway 0.5.0 test1 is a universal build, so it runs natively on both Apple
Silicon and Intel Macs.

## Installing

1. Open the disk image you were sent.
2. Drag **Onceaway** onto the **Applications** folder shown next to it.
3. Eject the disk image.
4. Open your Applications folder and launch **Onceaway**.

## The first launch may be blocked

This is a test build, and test builds are not notarized by Apple. The first
time you open it, macOS may say it cannot verify the app.

This is expected. To open it:

- **Right-click** (or Control-click) Onceaway in Applications and choose
  **Open**, then **Open** again in the dialog.

If that does not offer you the option:

- Open **System Settings → Privacy & Security**, scroll down, and click
  **Open Anyway** next to the message about Onceaway.

You only need to do this once. Do not turn off macOS security settings to get
around it — you do not need to, and you should not have to.

## Updating

There is no automatic updater. New builds arrive as a new disk image, and you
install them the same way. Your history, reviews and settings are kept.

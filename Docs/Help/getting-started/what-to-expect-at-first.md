# What should I expect at first?

For the first day or two, probably nothing. That is normal, and it is not a
fault.

## Why it takes a little while

Onceaway only reports something once it has seen the same structure **more than
once**. A task you did today for the first time is not repeated work yet. It
becomes interesting when it happens again, and more interesting when it happens
on a different day.

So the honest answer is: install it, turn observation on, and then forget about
it for a few days while you work normally.

## What to expect, roughly

- **Day one:** empty screens with a short explanation on each. This is correct.
- **After a few working days:** the first patterns appear, and the bell in the
  top right tells you something needs a decision.
- **After a week or two:** confirmed patterns start being weighed as
  opportunities, and Insights has enough history to show trends.

## What would make it faster

Nothing artificial, and that is deliberate. Onceaway will not invent examples
or pad the list to look busy. If you want it to see more of your real work,
the two things that help are leaving observation running and — if it suits you
— turning on browser context so web work is understood more precisely.

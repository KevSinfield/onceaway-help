# Onceaway 0.5.0 test1

The first Onceaway build that can be installed on another Mac.

## What's in it

- **First-run setup** — a six-step welcome guide that explains what Onceaway
  observes, keeps everything optional, and can be left and resumed.
- **Help** — a permanent Help section in the app, plus **Run setup again**.
- **Patterns, Opportunities and Recommendations** — notice repeated work,
  confirm it, weigh it, and ask for ideas when you want them.
- **Insights** — what has been happening with your repeated work over time,
  with no score of any kind.
- **Notifications** — a bell that tells you when something needs a decision,
  and stays quiet otherwise.
- **Choice of AI provider** — Anthropic or OpenAI, with the key kept in your
  Keychain and read only when you ask.
- **Assist** — one assisted action: moving a single file you chose into a
  folder you chose, after you approve the exact move.
- **App and menu-bar identity** — a proper Dock icon, and a menu-bar ring that
  is solid while observing and dashed while not.
- **Universal build** — runs natively on Apple Silicon and Intel.

## Known caveats

- **This is a test build and it is not notarized.** The first launch is blocked
  by macOS until you approve it. See
  [Onceaway won't open](../troubleshooting/onceaway-wont-open.md).
- **There is no automatic updater.** New builds arrive as a new disk image.
- **Observation is off by default.** You start it yourself from the menu bar.
- **Assist does one thing.** Moving a single file you chose. Nothing else.
- **There is no billing and no account backend.** Everything commercial in the
  app is a preview of an idea.
- **AI needs your own provider API key.** There is no built-in AI, and no local
  model.
- **File activity covers Downloads and Desktop only**, and browser context
  covers Safari and Google Chrome only, and is off until you turn it on.

## Requirements

macOS 15 or later.

# How to use notifications

The bell in the top right holds anything waiting for a decision. A number on it
means there is something unread.

## Reading them

Click the bell. Each entry says what kind of thing it is and what it concerns.
Click one and Onceaway takes you straight to the relevant screen — the Pattern
to review, the Opportunity to answer, the suggestion to read.

Clicking a notification only navigates. It never performs an action, never
moves a file, and never sends anything to an AI provider.

## Marking as read

Opening an entry marks it read. **Mark all as read** clears the badge in one
go without opening anything.

Read state is remembered between launches for the durable kinds, so you are not
shown the same thing twice.

## Dismissing

Dismissing removes an entry you do not want to see. It does not change the
underlying situation: the Pattern still needs a review, you have simply said
you do not want to be reminded about it here.

## They come and go on their own

Notifications are worked out from Onceaway's current state, not stored as an
inbox. Review the Pattern and the "review needed" entry stops existing, because
there is nothing left to tell you. This is normal.

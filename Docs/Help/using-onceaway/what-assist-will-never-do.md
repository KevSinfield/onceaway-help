# What Assist will never do

Three questions people reasonably ask, with the same answer each time.

## Can AI start an Assist action automatically?

No.

An AI suggestion is text on a screen. It has no route to the part of Onceaway
that touches files. Reading a suggestion that says "you could move these into a
folder" does not create, arm or queue an action — you would still choose the
file, choose the destination, read the preview and approve it yourself.

## What happens if I cancel?

Nothing happens. That is the whole answer.

Cancelling before you press **Perform Move** leaves everything exactly as it
was. No file is moved, nothing is queued for later, and nothing is remembered
about the attempt.

If a protected context interrupts you, the action is cancelled the same way,
and clearing the protected context does **not** resume it. You would start
again deliberately.

## Does Assist continue after I quit Onceaway?

No. Nothing pending survives a quit.

If you quit — or the app stops unexpectedly — while a preview is on screen
waiting for approval, that action is gone. Reopening Onceaway brings Assist
back to its starting state, ready to help, with nothing half-done. No action
resumes on relaunch, ever.

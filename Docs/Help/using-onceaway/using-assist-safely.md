# How to use Assist safely

Assist moves one file you chose into one folder you chose, after showing you
exactly what it will do. The safety comes from the order of the steps.

## Before it appears

Assist is offered only when three things are true: the Pattern is **confirmed**,
you said you would like help reducing it, and the activity is one of the shapes
Onceaway currently supports.

## The four steps

**1. Choose the file.** Press **Choose file**. A normal macOS panel opens and
you pick the file. Choosing it does not move it.

**2. Choose the destination.** Press **Choose destination** and pick the
folder. Choosing it does not move anything either.

**3. Read the preview.** Onceaway shows the action in plain words: this file,
from this folder, to this folder. Nothing has happened yet. This is the moment
to check it.

**4. Approve.** Press **Perform Move**. This is the only step that changes
anything on disk, and it moves exactly one file.

You can press **Cancel** at any point before step 4.

## The safeguards

- **It never overwrites.** If the destination already contains a file with that
  name, Onceaway stops and changes nothing.
- **It never deletes.**
- **It is one file.** Not a batch, not a folder, not a rule that keeps running.
- **It is paused in protected contexts.**
- **The file you choose is not observed.** It is used to perform the move, not
  added to your history, not kept afterwards and never sent anywhere.

## If it fails

Onceaway tells you plainly and nothing else is changed — the file was not
there any more, the destination could not be written to, the name already
existed, or macOS did not permit access. Start again when you have sorted it.

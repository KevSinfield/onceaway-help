# Assist isn't available

Assist appears on a Pattern only when several things line up. Check them in
this order.

## 1. Is the Pattern confirmed?

Assist is never offered for an unreviewed or rejected Pattern. Open the Pattern
and answer **Yes** under **Your review** if it really was the same task.

## 2. Did you say you want help with it?

Under **Your preference**, answer **Yes — I'd like help reducing this**. Assist
and Reduction both stay hidden until you do.

## 3. Is it a supported activity?

Onceaway 0.5.0 has exactly one assisted action: moving a single file you chose
into a folder you chose. If the Pattern is not that shape, Assist will say it
does not have a safe assisted action for this activity. That is honest rather
than broken.

## 4. Is Onceaway in a protected context?

Assist is paused while a protected context is active. Leave that context and
start again. Clearing it does not resume a cancelled action, by design.

## Assist stopped part-way through

If you quit while a preview was waiting, the action is gone and Assist is back
at its starting state. Nothing pending survives a quit. Start again.

# Insights looks empty

Insights is built from repeated work, not from raw activity, so it stays empty
until there are Patterns to describe.

## Why it is empty

**You have no Patterns yet.** This is the usual reason and it resolves itself
with time. Insights has nothing to summarise until Onceaway has noticed the
same structure more than once. See
[Why hasn't Onceaway noticed anything yet?](../observation/why-hasnt-onceaway-noticed-anything-yet.md).

**Observation is off.** Check the ring in your menu bar. Dashed means off.

**The period is too short.** Switch from **7 days** to **30 days**. Repeated
work that spans weeks will not show in a seven-day window.

**Retention is shorter than the period.** If your history is kept for 7 days,
a 30-day view can only show what still exists. Check **Settings → Privacy →
Activity History**.

**You cleared your history.** Clearing removes observed activity, reviews and
preferences, so Insights starts again from nothing.

## What "empty" should look like

A short explanation, not a broken screen. If you see blank panels with no
message, that is worth reporting.

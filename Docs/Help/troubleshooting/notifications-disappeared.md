# Notifications disappeared

This is usually correct behaviour rather than a fault.

## Notifications are not an inbox

They are worked out from the state Onceaway is currently in. When the situation
behind one is resolved, the notification stops existing, because there is
nothing left to tell you.

So a "review needed" entry disappears once you reviewed the Pattern, and an
"opportunity ready" entry disappears once you answered it. Nothing was lost.

## Ideas-ready entries do not survive quitting

Reduction suggestions live for the current session only and are not stored, so
a notification about one cannot outlive the app. Quit Onceaway and both the
suggestion and its notification are gone.

To get the suggestion again, ask for it again.

## Did you dismiss it?

Dismissing removes the entry without changing the situation. The Pattern still
needs reviewing — you just said you did not want reminding here. Open Patterns
directly and you will find it.

## Read state is remembered

For the durable kinds, read and dismissed state persists between launches, so
you are not shown the same thing repeatedly.

## Nothing to see at all

An empty bell means nothing needs a decision right now. On a new installation
that is the expected state.

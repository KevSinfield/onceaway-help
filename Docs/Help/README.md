# Onceaway Help

> These articles describe the **Onceaway 0.5.0 test build**. Some setup and
> installation details will change before public release. Anything described as
> *planned* or *not available yet* is exactly that.

Onceaway notices work you repeat on your Mac, helps you decide what is worth
reducing, and can assist with selected tasks when you choose.

**New here?** Start with [What is Onceaway?](getting-started/what-is-onceaway.md),
then [Installing Onceaway](getting-started/installing-onceaway.md).

**Nothing showing up?** [Why hasn't Onceaway noticed anything yet?](observation/why-hasnt-onceaway-noticed-anything-yet.md)

**Want the privacy answers?** [What does Onceaway observe?](privacy-security/what-does-onceaway-observe.md)
and [What does it never record?](privacy-security/what-onceaway-never-records.md)

# Can I exclude apps or websites?

Yes. **Settings → Privacy → Never Observe** is your own exclusion list.

## Adding an app

Click **Add Application…** and pick it. From then on, Onceaway will not collect
detailed context from inside that app.

The app's **name** can still appear in your activity timeline — you will still
see that you switched to it — but nothing is collected about what happened
inside it.

## Removing one

Select it in the list and remove it. The change takes effect immediately.

## What about individual websites?

There is no per-site exclusion list in Onceaway 0.5.0. The controls you have
for web activity are:

- Turn **browser context** off entirely, per browser, so no hostnames are
  recorded at all. This is the default.
- Exclude the browser application itself under **Never Observe**.
- Rely on financial and other protected contexts, which suppress observation
  automatically.

Per-site exclusions are not available yet.

## The list Onceaway will not let you change

**Always Protected** — password managers and credential apps — is protected by
default and cannot be turned off.

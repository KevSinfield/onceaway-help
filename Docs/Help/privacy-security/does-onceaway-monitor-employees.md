# Does Onceaway monitor employees?

No. Onceaway is designed to help a person reduce their own repeated work — not
to score, rank or watch anybody.

## Why it is not a monitoring tool

The design works against it, deliberately:

- **The data is local.** History stays in a database on the Mac it was observed
  on. There is no server, no account and no way to collect it centrally.
- **There is no reporting.** Nothing exports a timesheet, a activity report or
  a summary for someone else to read.
- **There are no scores.** No productivity rating, no focus figure, no
  time-wasted judgement. Nothing that could be put in a league table.
- **The person is in control.** Observation is off until they start it, they
  can pause it at any moment, they choose which folders are watched, and they
  can clear their history whenever they like.
- **The detail is not there.** No keystrokes, no screen contents, no file names,
  no page contents. Even if someone did read the database, it would not tell
  them what work was done — only that a shape of activity recurred.

## If you are considering it for a team

The honest answer is that Onceaway would not tell you what you were hoping to
learn. It is built to help the person using it notice their own repetition.
Pointing it at somebody else is not a use it supports.

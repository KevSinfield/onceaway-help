# What does Onceaway never record?

This list is short and it is meant to be exact.

## Never captured

- **What you type.** There is no keystroke recording of any kind.
- **Password and secure-field contents.** Typing in a secure field creates a
  protected moment before anything detailed is recorded.
- **Clipboard contents.** Onceaway does not read your clipboard.
- **Screen contents.** Onceaway does not capture, read or analyse your screen.
- **File names.** Passive observation records the file's type and folder
  category, never its name.
- **File paths.** No full or partial paths are stored.
- **Web addresses.** With browser context on, the host is recorded. The path,
  the query, and the rest of the address are not.
- **Page contents.** No page text, no form values, no document contents.
- **Banking or payment field values.** Financial contexts suppress detailed
  observation.

## How to read this list

These are statements about what Onceaway records, and they hold because it
never asks macOS for that information in the first place. Onceaway uses no
accessibility monitoring, no screen recording, no keyboard or mouse monitoring
and no clipboard access.

The one deliberate exception to "no names" is Assist, and it is not passive
observation: when **you** choose a file for an assisted move, Onceaway
obviously has to know which file you picked. It uses it to perform that one
move and does not add it to your history or keep it afterwards.

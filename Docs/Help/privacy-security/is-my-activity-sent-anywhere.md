# Is my activity sent to Onceaway servers?

No. There is no Onceaway server for it to be sent to.

## What that means precisely

Onceaway 0.5.0 has no account system, no sign-in, no cloud backend, no
analytics and no telemetry. Your observed activity, your Pattern reviews and
your preferences stay in the local database on your Mac. Nothing about them is
uploaded, and there is nowhere for them to be uploaded to.

## The one time anything leaves your Mac

When **you** explicitly ask for an AI interpretation or for reduction ideas,
Onceaway sends a small, privacy-minimised description of that one Pattern
directly to the AI provider you selected, using your own API key. That request
goes to the provider, not to Onceaway.

If you never add an API key, nothing ever leaves your Mac.

Exactly what is included in that request is set out in
[What does Onceaway send to AI?](../ai/what-does-onceaway-send-to-ai.md).

## Crash reports and usage statistics

There are none. Onceaway does not collect or transmit usage data, and it does
not upload crash reports. If something goes wrong, you tell us — nothing tells
us on your behalf.

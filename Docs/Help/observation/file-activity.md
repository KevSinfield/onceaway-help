# File activity observation

Onceaway can notice when files are created, renamed or moved — in the folders
you allow, and at a deliberately coarse level of detail.

## Which folders

Two are available: **Downloads** and **Desktop**. You choose which are
included, under **Settings → Privacy → File Activity**.

These two are where repeated file work usually lands, and keeping the list
short and explicit is intentional. Onceaway does not roam your disk.

## What it records

For each event, two things: the **file type** (its extension, such as `pdf` or
`png`) and **which of those folders** it happened in.

A real record looks like *"a PDF was created in Downloads"*.

## What it does not record

- Not the file's name.
- Not its path.
- Not its contents.
- Not its size, author or any other metadata.

Nothing is collected at all while Onceaway is in a protected state.

## Why so little?

Because it is enough. To notice that you save the same kind of file to the same
place several times a week, the type and the folder are all that is needed. The
name would tell Onceaway more about you without telling it anything more about
the repetition.

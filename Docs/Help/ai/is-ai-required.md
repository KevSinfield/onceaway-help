# Is AI required?

No.

## What works without any AI at all

Everything except two features. With no API key configured, Onceaway still:

- observes activity,
- finds repeated work and creates Patterns,
- lets you review and label them,
- weighs confirmed Patterns as Opportunities,
- records what you want reduced,
- shows Home, Patterns, Opportunities, Insights and History,
- raises notifications,
- performs the assisted file move.

The detection of repeated work — the core of the product — is done entirely on
your Mac and does not involve a provider at any point.

## What AI adds

Two optional things, both of which you have to ask for by pressing a button:

- **Interpretation** — describing a Pattern in plain words.
- **Reduction ideas** — suggesting ways you might reduce a repeated task.

## Why it is optional rather than built in

Because local usefulness should not depend on an external service, a network
connection, or somebody's billing arrangement. See
[Why Onceaway keeps AI optional](why-onceaway-keeps-ai-optional.md).

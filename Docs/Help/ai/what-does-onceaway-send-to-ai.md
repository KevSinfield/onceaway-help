# What does Onceaway send to AI?

Only a small, privacy-minimised description of the one Pattern you asked about
— and only after you press the button.

You can see exactly what will be sent before sending it: tick **Preview what
will be sent** in the panel.

## Interpretation

When you ask Onceaway to describe a Pattern in plain words, it sends the
structural description of that Pattern:

- application names,
- website hostnames, where browser context is enabled,
- coarse file actions, meaning the file type and folder category,
- how many times and over how many days it recurred.

It does **not** send your review, your label, or anything about any other
Pattern.

## Reduction ideas

When you ask for ways to reduce a Pattern, it sends the same structural
description, **plus the short label you wrote yourself** — because that is the
piece that makes the suggestion useful, and you chose the words.

If you did not write a label, none is sent. Nothing writes one for you.

## What is never sent, in either case

- Raw file paths.
- File names.
- Full web addresses, query strings or page contents.
- Passwords or secure-field contents.
- Clipboard contents.
- Screen contents or screenshots.
- Your activity history as a whole.
- Anything from a protected or excluded context.

## When nothing is sent

- While you have not pressed the button.
- When you switch provider.
- When you open Settings or the AI pane.
- At launch, or in the background.
- While Onceaway is in a protected state.

## What comes back

Text, which Onceaway shows you as a suggestion. It is not stored, it does not
survive quitting, and — importantly — it cannot cause anything to happen. See
[Why Onceaway asks before it acts](../using-onceaway/why-onceaway-asks-before-it-acts.md).

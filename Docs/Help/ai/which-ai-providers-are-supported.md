# Which AI providers does Onceaway support?

Two, in Onceaway 0.5.0:

- **Anthropic**
- **OpenAI**

You pick one, and it handles your explicit AI requests. Each keeps its own API
key, and each has its own model setting.

## Do I need both?

No. One is enough, and none is fine too — see
[Is AI required?](is-ai-required.md).

## Which should I choose?

Either works for both jobs Onceaway uses AI for. If you already have an API key
with one of them, use that one. Switching later is a single click and costs you
nothing.

## What about local or on-device models?

Not supported yet. Onceaway does not run a model on your Mac, and it does not
connect to a locally hosted one. **Planned** — but not available today, and
nothing in the app implies otherwise.
